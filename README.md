# ObjektiYksi

**Object one. Trying to grasp for it.**

This repository tests a concrete computational-physics idea that grew out of `ResonantNeuron`, `SighImageSuper`, `FunctionalArbors`, `Dig`, `TheMycelialCortex`, and `DendriteAsIteratedFeedbackOperator`:

> **Persistent physical structure can act as memory by generating an operator when queried; slow local changes rewrite the structure, so later queries expose a different family of operators.**

The experiments are deliberately small, deterministic, and attackable. This is not a claim that cortex is an acoustic cavity, that arbitrary AI matrices can be stored in this lattice, that biological credit assignment is solved, or that this simulator has a hardware advantage.

## The object

The persistent state is one material vector `g`, not a bank of explicit learned matrices.

At fixed material, the resonant lattice is linear:

```math
H_g(\omega)=\left[K(g)-\omega^2I+i\omega\Gamma\right]^{-1}.
```

Input/output ports expose an effective transfer operator

```math
M_g(a)=P_{\mathrm{out}}H_g(\omega)P_{\mathrm{in}}(a),
```

where the address `a` may include source position, carrier frequency, or port choice. For a vector input `x`,

```math
y=M_g(a)x.
```

The current picture is therefore:

```text
persistent memory       g
question / address      a
exposed weight-like map M_g(a)
input                    x
computation              y = M_g(a)x
slow local learning      g -> g'
next query               exposes M_g'(a)
```

The matrix-like object is generated by the material when queried. It is not separately stored as a digital array.

## What the gates established

GitHub Actions reproduces the full Gates 0–12 stack on Python 3.11 and 3.12.

### Gates 0–1 — topology is an operator, not merely a road

Gate 0 starts from mirror-symmetric material and uses an exact forward/reference sensitivity as a positive-control write rule. A fixed material budget is redistributed so later source-only replay strongly favors a chosen receiver.

Gate 1 shows why shortest-path language is insufficient: the learned target can be the strongest resonant output even when an ordinary `1/g` graph path is cheaper to a decoy.

The functional object is therefore **material arrangement + phase + resonance + frequency**, not merely connectivity.

### Gates 2–3 — local dither plus scalar consequence can carve it

Gate 2 removes the analytic gradient and reciprocal receiver reference from learning. Every proposal transfers material between two adjacent couplings while conserving the total. One delayed scalar consequence decides keep/revert.

Gate 3 makes the strongest competing output move during learning without telling the structural rule which competitor caused the error. The target still becomes rank-1 in every run.

### Gates 4–5 — one material supports a family of relations

Gate 4 freezes learned material and varies source position and frequency. The same `g` exposes different transfer behavior depending on how it is queried.

Gate 5 trains one conserved material against several source landing positions simultaneously. With the longer budget, all five trained sources become rank-1 and nearby unseen positions partially generalize.

### Gates 6–7 — learned addressing, then a kill test

Gate 6 adds a fast task-to-address selector while material changes more slowly. Gate 7 then removes address degrees of freedom to see what was actually necessary:

```text
full position x frequency   median worst ratio  1.70577   rank-1 100%
position only               median worst ratio  1.70236   rank-1 100%
frequency only              median worst ratio  0.999996  rank-1 66.7%
```

Position-only retains `99.80%` of the full margin. Frequency remains part of the physical transfer function, but it did not earn the claim of being a necessary learned address coordinate in that task.

### Gates 8–9 — material can rewrite what a physical address means

Gate 8 forces a non-native crossed map at one frequency:

```text
upper source  -> lower target
center source -> upper target
lower source  -> center target
```

The blank lattice has only `0.10978x` worst crossed relation. After conservative local learning, the median worst relation is `1.52250x`, the worst seed is `1.36263x`, and all three crossed relations are rank-1 in every seed.

Gate 9 audits the actual source-coordinate optimum. Before learning, every target prefers its native source. After crossed learning, the imposed crossed source is audit-best for all three targets in all three seeds.

So slow material deformation can change not just response strength at an address, but **what that address means downstream**.

## Gate 10 — dense operator readback

Gate 10 changes the unit of analysis from one-hot routing to a true vector-space transformation. Three left input ports and three right output ports expose a dense complex `3x3` matrix:

```math
M_g=C\left[K(g)-\omega^2I+i\omega\Gamma\right]^{-1}B.
```

A hidden physically reachable material generates a teacher operator. Student material starts blank and sees only three dense random complex input vectors and their outputs. Basis vectors are never used during learning.

After learning stops, basis queries reconstruct the matrix column by column:

```text
blank matrix error                    55.2588% median
reconstructed matrix error             1.7686% median
worst learned seed                     2.7142%
blank held-out dense-probe error       54.3629% median
learned held-out dense-probe error      1.5592% median
random-drift matrix error              59.7667% median
```

Then the same learner is asked to fit an unrelated dense complex matrix not generated by any known lattice material:

```text
blank arbitrary-target error          145.6234% median
learned arbitrary-target error         73.1030% median
learned held-out error                 70.7990% median
```

So the strong claim dies: this is **not arbitrary matrix RAM**. What survives is a learnable, physically realizable operator family.

## Gates 11–12 — can one material hold more than one dense operator?

This is the first direct test of the reason the architecture might be more interesting than an inconvenient implementation of one matrix.

Two frequency addresses are fixed:

```text
A: omega = 1.20
B: omega = 1.55
```

Each exposes its own dense `3x3` transfer matrix from the same material.

### Gate 11A — compatible slices of one hidden material

Both target matrices come from one hidden material, so an exact common `g` exists by construction.

```text
blank median worst matrix error       68.6673%
learned median worst matrix error      5.1920%
learned median worst held-out error    4.8928%
random-drift median worst error       72.2012%
```

One persistent material can therefore recover multiple dense addressed operators when they are known-compatible slices of one physical family.

### Gate 11B — separately specified operators

The harder attack gives each frequency a target generated by a different hidden material. Each target is first shown to be easy alone:

```text
omega=1.20 isolated median error       2.1744%
omega=1.55 isolated median error       6.2731%
```

With one shared `g` and the original 2400-proposal budget:

```text
shared-g median worst matrix error    11.2311%
shared-g median worst held-out error  10.8406%
```

That narrowly missed the preregistered `10%` bar. Gate 11 therefore recorded interference, but deliberately did not call it a hard capacity limit.

### Gate 12 — the “collision” was optimization friction in this case

Gate 12 starts from the exact Gate-11 endpoints and attacks the capacity interpretation in three ways.

First, it computes the exact material Jacobian for both matrices,

```math
\frac{\partial M}{\partial g_e}
=-(C H b_e)(b_e^T H B),
```

and projects it into the fixed-total-material tangent space. The two complex `3x3` operators contain 36 real output coordinates in total.

```text
stacked tangent rank                  36 / 36 in every seed
median gradient cosine               -0.07937
median best linearized residual ratio 3.70e-15
```

There is coupling: a correction optimized for one address is predicted to damage the other. But the **joint** tangent still has all 36 real directions and can cancel the stacked residual to numerical precision at first order.

Second, an explicitly audit-only exact-Jacobian Gauss–Newton diagnostic is allowed five nonlinear backtracked steps from the same endpoint:

```text
median worst matrix error             4.04e-8
worst seed worst matrix error         5.11e-8
median worst held-out error           3.99e-8
```

So for these two independently specified target matrices, a common material state actually exists to essentially numerical precision. Gate 11 did not expose a representational impossibility.

Third, the original derivative-free local keep/revert learner is simply given 7200 more proposals—no gradient, no oracle update:

```text
Gate-11 endpoint median worst error   11.2311%
continued-local median worst error     5.2831%
continued-local worst seed             6.9466%
continued-local median held-out error  5.0762%
```

Every seed crosses the original `10%` criterion.

Gate 12 verdict:

```text
gate11_near_miss_was_budget_limited_local_search_rescues
```

The stronger statement now supported by this toy is:

> **One conserved material state can simultaneously realize two separately specified dense operators at two physical addresses, and a derivative-free local learner can find a useful shared solution from dense examples.**

The qualification matters just as much:

> **This has been shown for one small two-address `3x3` construction, not for arbitrary matrix pairs, many addresses, or scalable model storage.**

## What this may be good for

The uninteresting interpretation is:

```text
ordinary matrix -> expensive resonator -> same matrix multiplication
```

There is no obvious win there.

The interesting object is instead

```math
\mathcal M_g=\{M_g(a)\}_{a\in\mathcal A},
```

where one persistent substrate generates a **family of related operators**, and one local structural edit deforms the whole family.

That makes several questions concrete:

- Can related transformations share one physical substrate?
- How many useful addressed operators fit before genuine interference appears?
- Which requested operator changes cooperate and which collide?
- What is the intrinsic dimension and geometry of the realizable operator manifold?
- Can a small address select among useful transformations while slow learning changes their shared substrate?
- Does a physical implementation ever gain energy, latency, robustness, or compactness over digital storage?

Gate 12 is important because it shows why those questions need actual falsification. The first apparent two-operator capacity wall vanished when the optimizer was given more room.

There is also a direct connection to the `Kompressori` line: operator interference can be studied through the shared sensitivity maps

```math
J_a=\frac{\partial\,\mathrm{vec}\,M_g(a)}{\partial g}.
```

Gate 12 shows both sides at once: address-specific corrections can interfere, yet the combined Jacobian can still contain a joint direction that satisfies both.

---

## Claim boundary

Gates 0–12 establish computational-physics behavior in a deterministic toy only. They do **not** establish:

- arbitrary dense matrix realizability;
- scalable multi-model storage or compression relative to digital weights;
- a hardware energy or latency advantage;
- a useful neural network or semantic intelligence;
- autonomous goals;
- biological dendritic credit assignment;
- that frequency is generally the best address coordinate;
- that two-operator compatibility will survive at larger matrix size or address count.

The biology-facing hypothesis remains separate and much less established than the physical-operator result.

## Where this line pauses

For now, the cleanest object in `ObjektiYksi` is not “a weird neural net” and not “matrix storage in a wave box.” It is:

> **a shared physical state that can be locally rewritten, queried through physical coordinates, and made to expose more than one recoverable linear operator.**

Gate 10 established one dense operator. Gate 11 showed the expected interference when two independently specified operators shared material. Gate 12 then killed the tempting capacity story by showing that the interference was not a hard wall for this pair: the original local learner crossed the bar with more search, and an exact diagnostic found an essentially exact common solution.

That is a good place to stop adding gates and move to the next question.
