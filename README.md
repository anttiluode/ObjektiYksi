# ObjektiYksi

**Object one. Trying to grasp for it.**

This repo tests one concrete idea that emerged from `ResonantNeuron`, `SighImageSuper`, `FunctionalArbors`, `Dig`, `TheMycelialCortex`, and `DendriteAsIteratedFeedbackOperator`:

> **A fast signal exposes an operator compiled by physical structure; slower local changes rewrite that structure; later signals therefore see a different operator.**

The experiments are intentionally small and attackable. This is not a claim that cortex is an acoustic cavity, that arbitrary AI matrices can be stored in this toy, or that the biological credit-assignment problem is solved.

## The object

The persistent state is one material vector `g`, not a bank of explicit learned matrices.

At fixed material, the resonant lattice is linear:

```math
H_g(\omega)=\left[K(g)-\omega^2I+i\omega\Gamma\right]^{-1}.
```

Choosing input and output ports exposes an effective operator

```math
M_g(a)=P_{\mathrm{out}}H_g(\omega)P_{\mathrm{in}}(a),
```

where the address `a` can include physical source position and, in principle, carrier frequency or other port choices.

So the current picture is

```text
persistent memory:       g
question / address:      a
exposed operator:        M_g(a)
input:                   x
computation:             y = M_g(a) x
slow learning:           g -> g'
next computation:        y' = M_g'(a) x
```

The operator is not stored as a digital array. It is generated by the current material when the material is interrogated.

## What the gates established

GitHub Actions reproduces the full stack on Python 3.11 and 3.12.

### Gates 0–1 — topology is an operator, not a road

Gate 0 starts from mirror-symmetric material and uses an exact forward/reference sensitivity as a positive-control write rule. After fixed-budget material deformation, source-only replay strongly favors the chosen receiver.

Gate 1 then shows why ordinary graph language is inadequate: the learned target can become the strongest wave output even when a static `1/g` shortest path is cheaper to the decoy.

The useful object is therefore not just wiring:

> **material arrangement + phase + resonance + frequency define the functional topology.**

### Gates 2–3 — local dither plus scalar consequence can carve it

Gate 2 removes the analytic gradient and reciprocal reference from learning. A proposal changes only two adjacent couplings:

```text
g_a <- g_a + delta
g_b <- g_b - delta
```

Total material is conserved exactly. The system keeps or rejects the perturbation using only a delayed scalar consequence.

Gate 3 makes the output competitor itself move: the learner is judged against whichever non-target output is currently strongest, without being told which one that is. The target still becomes rank-1 in all runs.

### Gates 4–5 — one material supports a family of relations

Gate 4 freezes learned material and moves the source and frequency. The same material exposes different transfer behavior depending on where and how it is queried.

Gate 5 then trains one conserved material against several source landing positions simultaneously. With the longer 1600-proposal budget, all five trained sources become rank-1 and unseen nearby sources partially generalize.

This establishes a family of useful source-conditioned relations rather than one static road.

### Gate 6 — fast address selection over slow material learning

Gate 6 adds a tiny fast selector. It starts without task-to-address knowledge and samples physical addresses using only scalar task utility while the shared material changes more slowly underneath it.

Across three tasks, the selector finds distinct useful addresses and shared material learning improves the worst-task margin beyond either selector-only or material-only controls.

The first tempting interpretation was that `(position, frequency)` jointly formed the task address. Gate 7 attacks that directly.

### Gate 7 — frequency is not needed for addressing in this task

The full 3x3 position-frequency address space was compared against position-only and frequency-only ablations under the same observer floor and proposal budget.

```text
full address space      median worst-task ratio  1.70577   rank-1 100%
position only           median worst-task ratio  1.70236   rank-1 100%
frequency only          median worst-task ratio  0.999996  rank-1 66.7%
```

Position-only retains `99.80%` of the full margin.

Verdict:

```text
position_dominated_joint_not_needed
```

So frequency remains a physical parameter of the operator, but it has **not** earned the claim of being a necessary learned address coordinate in this toy.

### Gate 8 — position is not merely native wiring

A stronger objection is that source position may only reveal the lattice's built-in upper/center/lower geometry.

Gate 8 therefore forces a non-native cyclic map at fixed frequency:

```text
upper source  -> lower target
center source -> upper target
lower source  -> center target
```

The blank lattice begins at only `0.10978x` worst relation with `0/3` rank-1. After 1200 conservative local pokes:

```text
median worst crossed relation   1.52250x
worst seed                      1.36263x
rank-1 crossed relations        3/3 in every seed
random structural drift         0.06725x median
```

Verdict:

```text
crossed_permutation_survives_native_geometry_attack
```

The material can therefore rewrite what a fixed physical source coordinate means downstream.

### Gate 9 — the best physical address itself moves

Gate 9 does not introduce a new learner. It audits the Gate-8 materials and asks whether the `argmax` over source positions changes.

Before learning, every target prefers its native source. After crossed learning, the source assigned by the imposed 3-cycle becomes the audit-best source for **all three targets in all three seeds**.

```text
blank assigned-address fraction          0.0
blank native-address fraction            1.0
crossed-trained assigned-address fraction 1.0
median minimum assigned-vs-old-native
utility advantage                        +1.00487
weakest individual advantage             +0.62322
```

Identity training, random drift, and no-write controls retain the native optimum.

Verdict:

```text
address_optima_move_with_learned_material
```

So slow material deformation can change not only transfer values under fixed coordinates but also which physical input coordinate is optimal for a target relation.

### Gate 10 — can the material hold and return a dense linear operator?

Gate 10 changes the unit of analysis from source-target routing relations to a full vector-space transformation.

Three left input ports and three right output ports expose a dense complex 3x3 transfer matrix

```math
M_g=C\left[K(g)-\omega^2I+i\omega\Gamma\right]^{-1}B.
```

#### 10A: hidden physically reachable operator

A hidden material state, created only by conservative local transfers, defines a teacher matrix. Student material starts blank and is shown only **three dense random complex input vectors** and their output vectors. The learner never sees the teacher material or basis vectors.

After 1600 local keep/revert pokes, all learning stops. Only then are basis inputs `e1,e2,e3` used to reconstruct the matrix columns.

```text
blank matrix error                    55.2588% median
reconstructed matrix error             1.7686% median
worst reconstructed seed               2.7142%
blank held-out dense-probe error       54.3629% median
learned held-out dense-probe error      1.5592% median
random-drift matrix error              59.7667% median
material conservation error             0.0 in consequence runs
```

This is no longer one-hot routing. The same physical substrate has been identified from ordinary dense input/output examples and later behaves as a learned linear transformation over a three-dimensional input space.

#### 10B: arbitrary dense-matrix attack

The identical learner is then asked to fit an unrelated dense complex 3x3 matrix that was **not** generated by any known material state.

It improves substantially, but fails the same recovery criterion:

```text
blank arbitrary-target matrix error    145.6234% median
learned arbitrary-target matrix error   73.1030% median
learned held-out error                  70.7990% median
```

So the stronger claim dies here.

Verdict:

```text
physically_reachable_operator_readback_succeeds_but_arbitrary_matrix_claim_fails
```

The supported statement is:

> **The material can store / system-identify dense operators that lie inside its realizable physical operator family, and those operators can be recovered later by black-box queries.**

The unsupported statement is:

> this is an arbitrary matrix store.

That distinction is central. The interesting object may be a **learnable operator manifold**, not a strange replacement for RAM.

## Why this might matter

If this survives larger tests, the potential advantage is not “use a huge resonator to perform an ordinary matrix multiply.” That would usually be a bad trade.

The interesting possibility is that one persistent substrate `g` generates a structured family

```math
\mathcal M_g=\{M_g(a)\}_{a\in\mathcal A},
```

and one local material edit deforms that whole family at once.

That creates questions ordinary matrix storage does not naturally ask:

- how many independently useful operators can one substrate expose?
- which operator edits interfere and which cooperate?
- does the family vary smoothly with physical address?
- what is the dimension of the realizable operator manifold?
- can related transforms share material more efficiently than separate matrices?
- can a fast selector navigate the operator family while slow learning reshapes it?

Those are now experimentally testable in this repo.

## What this does **not** establish

Gates 0–10 establish only computational-physics behavior in a deterministic toy.

They do **not** establish:

- a hardware energy or latency advantage;
- arbitrary dense matrix realizability;
- a replacement for digital matrix multiplication;
- semantic intelligence or a useful neural network;
- autonomous goals;
- biological dendritic learning or credit assignment;
- that frequency is a necessary address coordinate in the present task.

`DendriteAsIteratedFeedbackOperator` remains relevant precisely because its first receipt-credit construction failed the spatial-specificity attack. The physics side is currently stronger than the biological-credit bridge.

## Next attack

Gate 10 says a single material can return one dense operator from its realizable family. The next useful question is the one that would make this substantially more interesting:

> **Can one shared `g` support several independently programmed dense operators at different addresses, when those target operators were not generated by the same teacher material?**

A clean Gate 11 should give two physical addresses two different dense teacher operators, train both through ordinary dense probes, and then reconstruct both matrices independently. If one target improves only by destroying the other, the shared-operator-family story has a hard capacity/interference limit. If both survive, measure how far that scales before collision.
