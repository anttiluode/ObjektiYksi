# Gate 11 — can one material hold two addressed dense operators?

Gate 10 showed that one conserved resonant material can be identified from dense input/output examples and later return one physically realizable dense `3x3` operator. Gate 11 asks the reason this architecture might be more interesting than an inconvenient matrix store:

> **Can one persistent material state `g` support more than one dense operator, selected by physical address?**

The address coordinate used here is frequency. Two fixed addresses are tested:

```text
slot A: omega = 1.20
slot B: omega = 1.55
```

At each address the same three left input ports and three right output ports expose

```math
M_g(\omega)=C[K(g)-\omega^2I+i\omega\Gamma]^{-1}B.
```

Training uses three dense random complex probes per address. Basis vectors are never used in a keep/revert decision. After all learning stops, `e1,e2,e3` reconstruct the full matrix independently at each frequency.

Every proposed structural update remains one local transfer of conserved material. The learner is given only one scalar joint consequence:

```math
J = \max(L_A,L_B)+0.25\,\mathrm{mean}(L_A,L_B),
```

where each `L` is normalized dense-probe error. The max term prevents the learner from winning by sacrificing one address.

The focused experiment was reproduced on Python 3.11 and 3.12. Numerical differences between the receipts were only floating-point roundoff; both produced the same verdict.

## 11A — compatible shared-family positive control

One hidden material `g*` generates **both** target matrices, one at each frequency. Therefore an exact single-material solution exists by construction.

Across three seeds:

```text
blank median worst matrix error        68.6673%
learned median worst matrix error       5.1920%
learned median mean matrix error        3.9793%
learned median worst held-out error     4.8928%
worst seed worst-matrix error          17.0797%
random-drift median worst error        72.2012%
```

This passes the preregistered joint-family criterion:

```text
median worst matrix error   <= 10%
median worst held-out error <= 10%
every seed worst error      <= 20%
median error                <= 35% of random control
```

So Gate 10 was not restricted to one frequency slice. A single learned material can recover more than one dense operator when those operators belong to one internally consistent physical operator family.

## 11B — independent-programming attack

The stronger test assigns each frequency a target generated by a **different hidden material**.

Each target is physically reachable by itself, but there is no guarantee that one common `g` can realize both simultaneously.

Before judging the joint fit, each target was trained alone from blank material using the same dense-probe principle.

```text
isolated omega=1.20
  median matrix error                  2.1744%
  worst seed                           4.1087%
  median held-out error                2.0956%

isolated omega=1.55
  median matrix error                  6.2731%
  worst seed                           7.5729%
  median held-out error                6.1176%
```

Both isolated targets therefore pass the fixed learnability control.

Now force one shared material to fit both independently specified targets:

```text
blank median worst matrix error        70.5606%
shared-g median worst matrix error      11.2311%
shared-g median mean matrix error        9.8341%
shared-g median worst held-out error    10.8406%
worst seed worst-matrix error           13.0422%
random-drift median worst error         86.1067%
```

The shared material improves both targets enormously and remains far better than random drift, but it misses the preregistered `10%` median-worst matrix and held-out thresholds.

Relative to the harder isolated target, the joint worst-address matrix error is

```text
11.2311 / 6.2731 = 1.790x
```

So the fixed Gate-11 verdict is:

```text
shared_family_recovered_but_independent_operator_programming_collides
```

## What this means

The clean positive result is:

> **One persistent material can represent and return multiple address-conditioned dense operators when those operators are compatible slices of one realizable physical family.**

The independent-programming result is more cautious:

> **Two separately specified, individually learnable operators interfere when forced into one shared material under this budget and learning rule.**

This is the first direct measurement of the cost of the fact that changing `g` deforms the entire family `M_g(omega)` at once.

It would be wrong to upgrade this near-miss into a proof of a hard representational incompatibility. The joint learner reached about `11%` worst-address error, only slightly outside the fixed `10%` criterion. A longer budget, a different local proposal distribution, or a better joint scalar objective might cross the line.

That ambiguity is now the next falsification target: **is the 1.79x joint penalty merely optimization friction, or is it a geometric collision in the realizable operator manifold?**

## Claim boundary

Gate 11 does **not** establish compression relative to digital matrices, scalable multi-task memory, arbitrary independent operator slots, or a hardware advantage.

It establishes a smaller but concrete distinction:

```text
same hidden material -> two addressed operators: recoverable
separate hidden materials -> each operator alone: recoverable
separate hidden materials -> one shared g: measurable penalty, misses fixed bar
```

That is exactly the interference question the operator-manifold interpretation predicted should exist.
